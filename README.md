# Liftlab

Personal, evidence-based training app. Plain HTML/JS (no build step), Firebase auth + Firestore, hosted on Netlify.

- `public/` is the site Netlify publishes
- `public/js/engine.js`: generator, progression, recovery, plates (pure functions)
- `public/js/exercises.js`: curated exercise library, equipment list, starting seeds
- `firestore.rules`: paste into Firebase console → Firestore → Rules

See `SPEC.md` for the agreed product spec.
